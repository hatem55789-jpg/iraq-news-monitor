# رصد الأخبار المجاني عبر GitHub Actions وTelegram

هذا نموذج تشغيل سحابي مجاني يعتمد على RSS، ويرسل **مقترحات فقط** إلى Telegram. لا يصمم ولا ينشر على فيسبوك. يحتاج حساب GitHub مجانيًا وبوت Telegram؛ لن يعمل قبل إكمال خطوات الربط أدناه.

## ما الذي يفعله

- يفحص موجز Google News RSS كل ساعة بين 8:00 و22:00 بتوقيت بغداد (البدء المخطط عند الدقيقة 7 من كل ساعة لتقليل تأخير ذروة التشغيل).
- يرتب القضايا الاجتماعية ثم الفكاهة المحترمة ثم الأخبار المهمة ثم موضوعات الحوزة.
- يستبعد كلمات الفنانين والأغاني، ويمنع تكرار الروابط.
- يرسل بحد أقصى خمسة تنبيهات في اليوم، ويتضمن كل تنبيه عنوانًا وملخص الموجز والمصدر والرابط.
- يحفظ عداد اليوم وبصمات الروابط في `state.json` لمنع التكرار. هذا الملف لا يحفظ رموز الدخول.

## حدود مهمة

- هذه مراقبة كلمات مفتاحية من موجز أخبار، وليست رصدًا شاملًا لمنصات التواصل أو لخوارزميات الترند. نتائج Google News وتوفر الـRSS قد يتغيران.
- لا يوجد تلخيص بالذكاء الاصطناعي؛ يستخدم وصف الخبر الموجود في الـRSS، أو يذكر أن الوصف غير متوفر.
- جدولة GitHub قد تتأخر أو تُسقط بعض التشغيلات وقت الضغط. GitHub يوقف الجداول في المستودع العام بعد 60 يومًا بلا نشاط؛ راجع صفحة Actions دوريًا.
- المستودع العام يجعل ملفات الكود مرئية للناس. لا تضع أي رمز أو بيانات شخصية في الملفات؛ الرموز تُحفظ في GitHub Secrets.
- ملفات الحالة تحفظ بصمات روابط وعدد التنبيهات، لا نصوص الأخبار ولا بيانات حساب Telegram.

## الإعداد

1. أنشئ مستودعًا عامًا جديدًا في GitHub باسم مثل `iraq-news-monitor`، ثم ارفع محتويات هذا المجلد كاملة مع الحفاظ على المسار `.github/workflows/iraq-news-monitor.yml`.
2. في Telegram افتح `@BotFather`، أرسل `/newbot`، واختر اسمًا ومعرّفًا للبوت. لا ترسل الرمز الناتج لأي شخص.
3. افتح محادثة البوت الجديد واضغط **Start**.
4. للحصول على رقم محادثتك، نزّل مجلد المشروع إلى حاسبتك، افتح Terminal/PowerShell داخله، شغّل `python get_chat_id.py`، ثم الصق رمز BotFather في المطالبة المخفية بعد أن تضغط **Start** للبوت. سيطبع الأداة رقم المحادثة محليًا فقط. لا تضع الرمز في أمر أو ملف.
5. أضف في المستودع: **Settings → Secrets and variables → Actions → New repository secret**. أنشئ السر `TELEGRAM_BOT_TOKEN` وضع فيه رمز BotFather، وأنشئ السر `TELEGRAM_CHAT_ID` وضع فيه الرقم الذي حصلت عليه. ثم افتح **Settings → Actions → General → Workflow permissions** وفعّل **Read and write permissions** لكي يحفظ النظام حالة التكرار والحد اليومي.
6. شغّل فحصًا يدويًا من **Actions → Iraq news monitor → Run workflow**، واختر `test_notification = true`. لا يبدأ مسح الأخبار بهذا الاختبار؛ يرسل رسالة اختبار فقط.
7. إذا وصلت رسالة الاختبار، أعد التشغيل مع `test_notification = false` لفحص RSS. بعدها يعمل الجدول تلقائيًا، بشرط وجود الملفات على الفرع الافتراضي وأن Actions مفعّلة.

### معرفة رقم محادثتك (Chat ID)

يحتاج Telegram إلى رقم المحادثة لكي يرسل البوت رسالة خاصة. يوفر `get_chat_id.py` طريقة محلية باستخدام Telegram Bot API بعد ضغط **Start**؛ يطلب الرمز بإدخال مخفي ولا يحفظه. احفظ الرقم الناتج كـSecret باسم `TELEGRAM_CHAT_ID`، ولا تضعه في ملف عام أو في نص الكود.

## تعديل المواضيع

عدّل `feeds.json` لتغيير عبارات البحث أو الكلمات. الكلمات المفتاحية لا تفهم السياق بدقة؛ راجع كل خبر قبل اعتماده للتصميم أو النشر. موافقتك تكون هنا في محادثة ChatGPT؛ الرد على Telegram لا يفعّل النشر.
