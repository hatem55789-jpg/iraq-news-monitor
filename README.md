# رصد الأخبار العراقي — الإعداد

ملفات الرصد السحابي موجودة في هذا المستودع. اتبع [دليل الإعداد بالعربية](README-ar.md) لإضافة أسرار Telegram بأمان، ثم شغّل اختبار الإشعار من تبويب **Actions**.

يعمل الجدول كل ساعة تقريبًا من 8 صباحًا إلى 10 مساءً بتوقيت بغداد. يرسل مقترحات إخبارية إلى Telegram فقط؛ لا يصمم ولا ينشر على Facebook.
